# Post drafts

Use `templates/post-draft.md`. The original draft is source evidence. Edit rather than rewrite unless explicitly asked, preserve the author's voice, and do not add unsupported facts. Separate original wording, current version, and editorial decisions. No external writing skill or personal style is required by the template.
