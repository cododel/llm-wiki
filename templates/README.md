# Editorial templates

Use the scaffold matching the record type for its Markdown body. Replace placeholders; submit title, slug, tags, metadata, relations and provenance as typed MCP fields. Templates contain no frontmatter persistence contract and are never imported or indexed automatically. The raw-source scaffold describes intake; it must never replace the original bytes.

The twelve types and discovery tags are defined in [SCHEMA](../SCHEMA.md). An ADR here is knowledge owned by an instance; service architecture decisions live in [docs/adr](../docs/adr/README.md).
